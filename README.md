# Планировщик обслуживания электрооборудования

Учебное Flask-приложение для темы 2.

## Возможности

- добавление электрооборудования;
- создание задач обслуживания;
- фильтрация задач по статусу и поиску;
- запуск задачи в работу;
- отметка задачи выполненной;
- JSON API для списка задач.

## Запуск

```powershell
pip install -r requirements.txt
python app.py
```

Сайт откроется по адресу `http://127.0.0.1:5000/`.

## Документация

Отчёт по заданиям 2-4 находится в папке `docs/`.
